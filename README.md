# Debt-tracker
# 💳 Учет Долгов

Веб-приложение для учета долгов и планирования выплат.

## Возможности
- ✨ Добавление и отслеживание долгов
- 📊 Визуализация прогресса выплат
- 💡 Три стратегии погашения долгов
- 🎨 Современный интерфейс

[Открыть приложение](https://xperialine2019.github.io/debt-tracker/)
